# 🎨 Frontend - AI Trading Dashboard

This frontend is built using React + Vite and provides a real-time trading interface with AI-powered trading features.


## 🚀 Features

- 📊 Real-time BTC price using WebSocket
- 📘 Live Order Book (BUY / SELL)
- 📜 Order History Table (Professional UI)
- 💰 Profit & Loss (PnL) calculation
- 🤖 AI Trading (manual + auto mode)
- 📈 Candlestick Chart (TradingView)
- ⚡ Fast UI with Vite (HMR enabled)


## 🏗️ Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- WebSocket (Binance API)
- TradingView Chart Library
- Fetch API
